Features

Everything you need for QA profiling

Built for speed and reliability — no cloud calls, no telemetry, no bloat.

GUID Rotation

Read, rotate, or set a custom Windows MachineGUID in seconds. A registry backup is created automatically before every write.

MAC Address Spoofing

Enumerate all network adapters and apply Locally Administered Addresses with built-in LAA bit validation.

Offline License Keys

HMAC-SHA256 signed keys with embedded tier, expiry, and creation date. Validation works with zero internet access.

Volume Serial Query

Enumerate all drives and read physical volume serial numbers via ctypes and fsutil — no external dependencies.

Registry Backups

Every write operation exports a timestamped .reg backup to backups/ before touching a single value.

Discord Bot Integration

Slash commands for key generation, revocation, audit logs, and role-gated admin actions — all managed from your server.
