System Identity

Rotate identifiers in one click

Change your Windows MachineGUID instantly. Ghost reads the current value, generates a new one, writes a timestamped backup, then applies the change — all without touching anything else on your system.

  • Read and display your current GUID at any time
  • Set a custom value or generate a random one
  • Automatic .reg backup before every write

Network

Manage MAC addresses across all adapters

Ghost lists every network adapter on your machine. Select one, enter a new MAC address or randomise it, and apply instantly. Supports Ethernet and Wi-Fi — per-adapter control with no system-wide restarts.

  • View all adapters and their current addresses
  • One-click address randomisation
  • Restore original address at any time
